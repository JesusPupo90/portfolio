# Software Developer Portfolio | Jesus Pupo

> **Bilingual Software Developer** specialized in web applications, e-commerce platforms, and custom management systems built with React, JavaScript, and Spec-Driven Development (SDD).

## 🛠️ Tech Stack & Architecture

- **Core:** React 18 + Vite (JavaScript)
- **Styling:** Tailwind CSS (Dark Luxury Custom Theme)
- **Localization (i18n):** `i18next` + `react-i18next` (Full ES/EN Support)
- **Icons & Animations:** Lucide React & Framer Motion
- **Deployment & Hosting:** Vercel

## 📐 Engineering Methodology: SDD

This project is built following **Spec-Driven Development (SDD)**. All functional requirements, UI/UX directives, design tokens, and acceptance criteria were formally specified before implementation.

You can inspect the technical specification file driving this build at [`docs/spec.md`](./docs/spec.md).
